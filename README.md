# com-mi

ระบบรับงาน commission สำหรับครีเอเตอร์ไทย — หน้าร้านที่แปะลิงก์ใน bio ได้
พร้อมคิวงาน ฟอร์มบรีฟ การชำระเงินผ่าน PromptPay และการส่งมอบไฟล์ที่ล็อกไว้จนกว่าจะจ่ายครบ

**เราไม่ถือเงินของใคร** ลูกค้าโอนเข้าบัญชีครีเอเตอร์โดยตรง แพลตฟอร์มเก็บค่าสมาชิกรายเดือน
ไม่หักเปอร์เซ็นต์จากออเดอร์ — เหตุผลทางกฎหมายอยู่ใน `docs/00-product-overview.md §5.1`

## เริ่มพัฒนา

```bash
pnpm install
cp .env.example .env.development.local   # แล้วเติมค่าจริง
pnpm db:migrate
pnpm dev                                  # http://localhost:3450
```

## กติกาที่ห้ามพลาด

- **ห้ามใส่ข้อความที่ผู้ใช้เห็นลงในโค้ดตรง ๆ** ทุกคำอยู่ใน `lib/i18n/dictionaries.ts` ทั้งไทยและอังกฤษ
- **เงินเป็นจำนวนเต็มหน่วยสตางค์เสมอ** ห้ามใช้ float
- **ราคาคำนวณใหม่ฝั่ง server ทุกครั้ง** request ส่งมาแค่ id ของสิ่งที่เลือก
- **สถานะออเดอร์เปลี่ยนผ่าน `assertTransition()` ที่เดียว** ห้ามเขียน `status` ตรง ๆ
- **แก้ `lib/payments/promptpay.ts` เมื่อไร ต้องสแกน QR ด้วยแอปธนาคารจริงใหม่ทุกครั้ง** —
  เทสต์พิสูจน์ได้แค่ว่าสตริงตรงสเปก ไม่ได้พิสูจน์ว่าเงินไปถึงบัญชีที่ถูกต้อง
- **ห้ามใส่เบอร์โทรหรืออีเมลจริงของใครในโค้ด** ใช้ `.env` ที่ไม่เข้า git

Next.js เวอร์ชันนี้มี breaking change จากที่คุ้นเคย — อ่าน `node_modules/next/dist/docs/`
ก่อนเขียนโค้ดที่แตะ API ของ Next (`middleware.ts` เปลี่ยนชื่อเป็น `proxy.ts` เป็นต้น)

## กับดัก DNS: wildcard กับ empty non-terminal

โซน `poruyrai.xyz` มี `ALIAS * → cname.vercel-dns-017.com` เป็นตัวพาซับโดเมนทั้งหมด
`com-mi.poruyrai.xyz` จึงเคยทำงานได้โดยไม่มีเรคคอร์ดของตัวเอง

พอเพิ่มเรคคอร์ดของ Resend ไว้ใต้ `send.com-mi` และ `resend._domainkey.com-mi`
ชื่อ `com-mi.poruyrai.xyz` กลายเป็น **empty non-terminal** — โหนดที่มีอยู่ในโซน
แต่ไม่มีเรคคอร์ดของตัวเอง และตาม RFC 4592 wildcard **จะไม่ครอบให้อีกต่อไป**
ผลคือเว็บหายทั้งเว็บ

สิ่งที่ทำให้หาสาเหตุยาก: มันไม่พังตอนแก้ DNS แต่พังตอน**แคชเดิมหมดอายุ**
ตอนเพิ่มเรคคอร์ดเสร็จใหม่ ๆ ทดสอบผ่านหมดทุกหน้า

**กฎ:** ซับโดเมนไหนที่ต้องเสิร์ฟเว็บ ต้องมีเรคคอร์ดของตัวเองเสมอ ห้ามพึ่ง wildcard
โดยเฉพาะเมื่อจะเพิ่มเรคคอร์ดลูกไว้ข้างใต้ (SPF/DKIM ของอีเมลคือเคสที่เจอบ่อยที่สุด)
